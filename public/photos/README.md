# Photos

Drop JPGs in this folder with these exact filenames. The site picks them
up automatically — no code change needed. Anything missing shows a
labelled placeholder instead of breaking.

| Filename        | What it should show                          | Best shape |
|-----------------|----------------------------------------------|------------|
| `hero.jpg`      | The main hero. A destination or ops scene.   | wide, 2400px |
| `about.jpg`     | Full-bleed band on the About page            | wide, 2400px |
| `cta.jpg`       | Background behind the closing call to action | wide, 2400px |
| `s1.jpg`        | Card: inquiry / first contact                | portrait   |
| `s2.jpg`        | Card: planning an itinerary                  | portrait   |
| `s3.jpg`        | Card: quoting / suppliers                    | portrait   |
| `s4.jpg`        | Card: booking / payment                      | portrait   |
| `s5.jpg`        | Card: traveller on the ground                | portrait   |
| `s6.jpg`        | Card: local operator / guide                 | portrait   |
| `t1.jpg` … `t3.jpg` | Small thumbnails, top-right of the hero  | landscape  |

## Licensing

Use images you have the right to publish commercially. Unsplash,
Pexels and Pixabay all permit commercial use; stock libraries you have
paid for obviously also work. Do not use images pulled from Google
Images or from another company's website.

Photos of identifiable people generally need a model release for
commercial use — the stock sites above handle that for you, a photo a
colleague took on their phone does not.

## Size

Keep each file under ~400KB. Anything larger and the page gets slow.
Any image editor, or `sips -Z 2400 file.jpg` in Terminal on a Mac, will
resize them.
